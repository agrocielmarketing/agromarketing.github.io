# Gerador do site Agrociel

O site é gerado a partir de modelos (pasta `templates`) e do conteúdo dos serviços (`conteudo-extraido.json`).

- Versão oficial (endereços limpos, liberada para o Google): `python3 _gerador/build.py`
- Versão de prévia (links com index.html e bloqueada para o Google): `python3 _gerador/build.py --previa`

Visual: `assets/css/site.css`. Interações: `assets/js/site.js`.
